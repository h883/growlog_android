# GrowLog 画面構成書（UI 再設計用）

このドキュメントは、GrowLog の**現在の画面構成をゼロから説明した資料**です。
コードを見なくても内容が分かるように書いてあります。UI デザインの検討にそのまま使えます。

---

## 0. アプリの前提

**GrowLog は「目標と、その進捗を記録して共有する SNS」です。**

一般的な SNS と違う点が2つあります。

1. **投稿に「目標」と「進捗パーセント」を紐付けられる。** 単なるつぶやきではなく、
   「何に取り組んでいて、どこまで進んだか」が主役です。
2. **「集中セッション」という機能がある。** 作業を始めるときにタイマーを起動すると、
   時間の経過に応じて植物や街などが少しずつ育ちます。これを他のユーザーも見られます。

プラットフォームは Android。片手持ちの縦画面が前提です。

---

## 1. 現在のデザインの方向性

現状は **X（旧 Twitter）を下敷きにした、白地・細線・青アクセント**です。

- 背景は純白。カードで区切らず、**1px の細い区切り線**でリストを仕切る
- 文字色は主文字がほぼ黒、副文字がグレー
- アクセントは1色の青のみ。ボタン・リンク・選択中タブに使う
- 「いいね」だけ例外でピンク
- フォローなどの主要ボタンは黒いピル型
- 角丸は控えめ。ボタンは完全なピル型（角丸50）、画像とカードは 12〜16
- 影はほぼ使わない。唯一の例外がボトムナビ
- ダークモードは背景を純黒にする

| 用途 | ライト | ダーク |
|---|---|---|
| 背景・カード | `#FFFFFF` | `#000000` |
| 沈める面（検索窓・入力欄・チップ） | `#F7F9F9` | `#16181C` |
| 主文字 | `#0F1419` | `#E7E9EA` |
| 副文字 | `#536471` | `#71767B` |
| 区切り線 | `#EFF3F4` | `#2F3336` |
| アクセント | `#1D9BF0` | 同じ |
| アクセント薄（進捗の溝・バッジ背景） | `#D3E9F8` | `#12354F` |
| いいね | `#F91880` | 同じ |
| 主要ボタン（フォローなど） | `#0F1419` | — |

文字サイズは本文 15sp / 行高 25.5sp が基準。見出し 18〜28sp、補助 12〜13sp。

## 2. 全体の骨格

### 2-1. ボトムナビゲーション（浮遊バー）

画面下部に**浮いている**バーです。画面幅いっぱいではなく、左右に余白を取った
角丸の島が影付きで浮きます。5項目。

```
ホーム / 見つける / 通知 / DM / マイページ
```

**特徴的なのは選択インジケータです。** 選択中の項目の位置で、バーの上辺が
円形にくり抜かれ、その穴から円形のボタンが浮き上がって見えます。
タブを切り替えると、このくり抜き位置がアニメーションで横に滑ります。

このバーの見た目は**既に確定していて、変更しない前提**です。

### 2-2. 投稿ボタン（FAB）

右下に青い円形の「＋」ボタン。ボトムナビの上に重なります。
投稿はメニューからではなく、常にここから行います。

### 2-3. バーとFABの表示条件

ボトムナビと FAB は、上記5画面にいるときだけ出ます。
詳細画面（投稿詳細・チャット・集中・グループなど）では両方消え、
代わりに画面上部に「← 戻る」付きのヘッダーが出ます。

### 2-4. ヘッダーの2種類

- **メイン画面用**: 左に青い「GrowLog」ロゴ、右にアイコンが並ぶ。高さ56dp、下に細い区切り線
- **詳細画面用**: 左に戻る矢印、その右に画面名。高さ53dp

## 3. 起動時の流れ

アプリを開くと、次の順に画面が切り替わります（フェードで遷移）。

### 3-1. 起動画面

GrowLog のロゴと葉のマークが中央に出るだけの画面。
アプリを起動するたびに必ず表示されます。裏でログイン状態を確認していて、
確認が終わるまで出続けます。

### 3-2. チュートリアル（未ログイン時のみ）

横スワイプする3ページ構成。各ページは中央に大きなイラスト、その下に見出しと説明文。
下部にページインジケータ（ドット3つ）、最下部に大きな青いボタン。

| ページ | 見出し | 説明 |
|---|---|---|
| 1 | GrowLogへようこそ | 完璧さよりも前進を。日々の小さな成長を記録し、仲間と共有しましょう。 |
| 2 | 挑戦を記録する | 目標と進捗を残すことで、昨日の自分を少しずつ超えていけます。 |
| 3 | 仲間と成長する | 応援やコメントを通して、あなたの挑戦を続ける力に変えましょう。 |

ボタンは1〜2ページ目が「次へ →」、3ページ目が「はじめる」。
その下に小さく「ログインはこちら」のテキストリンク。

### 3-3. アカウント作成

見出し「プロフィールを充実させましょう」＋説明文。
中央に円形のアイコン登録ボタン（タップで画像選択）。
その下に入力欄が縦に並びます。

- 名前（例：山田 太郎）
- ユーザー名（補足文：一意のハンドルネームを設定してください。）
- 自己紹介（複数行。補足文：あなたの目標や、取り組んでいることについて教えてください。）

最下部に「戻る」と「登録する」の2ボタン。

### 3-4. ログイン

中央に「ログイン」の見出しと「あなたの挑戦を記録しましょう」の一文。
その下に Google のロゴ付き「Googleでログイン」ボタン1つだけ。

## 4. メイン5画面

### 4-1. ホーム

```
┌────────────────────────────┐
│ GrowLog          🔥 🔍 🔔  │  ← ヘッダー
├────────────────────────────┤
│ いま集中中 3人              │  ← 集中中の人がいるときだけ出る帯
│  (👤)  (👤)  (👤)          │     横スクロール

│  資料作成 設計  勉強         │
├────────────────────────────┤
│  おすすめ   フォロー中   最新 │  ← 等幅3タブ
│  ━━━━                      │     選択中のみ短い下線
├────────────────────────────┤
│ (投稿カード)                │
│ (投稿カード)                │

```

ヘッダー右のアイコンは左から **炎（集中画面へ）／虫めがね（検索へ）／ベル（通知へ）**。

**集中中レール**は誰も集中していなければ丸ごと消えます。
アバターは44dp、その右下に育成中の絵文字（15sp）を重ねます。
下に作業内容を10spで1行、はみ出したら省略。タップで集中画面へ。

タブ切り替えでリスト内容が入れ替わります。引き下げて更新できます。

**空のとき**は中央に一文のみ。
「この1週間の投稿はまだありません」「フォロー中のユーザーの投稿はまだありません」「投稿がまだありません」

```

├────────────────────────────┤
```

## 5. 集中セッション（このアプリの中心機能）

### 5-1. コンセプト

作業を始めるときにタイマーを起動します。**経過時間はパーセントで見せません。**
代わりに、選んだテーマのものが6段階で育っていきます。

段階は 0〜5 の6つ。予定時間を設定した場合は、その時間を最終段階として等分します。
30分でも2時間でも、同じ割合で進みます。予定時間なしなら 15分/30分/60分/90分/120分 が区切りです。

**テーマは7種類**あり、開始時に選びます。

| テーマ | 段階0 → 5 |
|---|---|
| ガーデン | 🌰 種を植えた → 🌱 発芽 → 🌿 若葉 → 🪴 大きく育つ → 🌳 木になった → 🌸 花が咲いた |
| 街づくり | 🚧 更地を整地 → 🧱 基礎工事 → 🏠 建物が建つ → 🏘 通りができる → 🏢 高層ビル → 🌆 街が完成 |
| ロボット | 📐 設計開始 → 🔩 フレーム完成 → ⚙️ モーター搭載 → 🔌 配線完了 → 💡 プログラム起動 → 🤖 ロボット完成 |
| 宇宙開発 | 📋 設計図を引く → 🔧 部品が届く → 🛠 機体を組む → ⛽ 燃料充填 → 🚀 発射台へ → 🌌 打ち上げ成功 |
| 焚き火 | 🪵 薪を組む → ✨ 着火 → 🕯 小さな炎 → 🔥 燃え上がる → 🎇 熾火が輝く → 🏕 満天の焚き火 |
| 水族館 | 💧 水を張る → 🐟 小魚が来た → 🪸 水草が育つ → 🐠 群れが増える → 🐋 大きな魚 → 🐳 にぎやかな水槽 |
| 冒険 | 🎒 旅の支度 → 🚶 出発 → 🌲 森を抜ける → ⛰ 山を越える → 🗺 目的地が見えた → 🏁 到達 |

**設計方針として、途中でやめても罰を与えません。** 枯れたり壊れたりする演出は入れず、
「今日はここまで育ちました。次回はここから続けられます」と伝えます。

現状は絵文字1文字で表現していますが、**ここは本来イラストにしたい部分**です。

## 9. 再設計で特に考えてほしいところ

現状の課題として認識している点です。

1. **育つものの表現が絵文字1文字。** ここがアプリの目玉なので、
   本来はイラストやアニメーションにしたい。6段階 × 7テーマ＝42パターンの
   絵が必要になるため、負担の少ない表現方法も含めて検討したい。

2. **空の状態が味気ない。** どの画面もグレーの一文だけで、
   次に何をすればいいかが伝わらない。

3. **X の模倣から一歩出たい。** 「目標と進捗」「育てる」という
   このアプリ固有の要素が、見た目に反映されていない。

4. **「今週の庭」が絵文字の羅列。** 積み重ねの嬉しさが伝わる見せ方にしたい。

5. **集中画面の情報量。** タイマー・段階・応援数・休憩数・今週の庭・
   他人の一覧が1画面に詰まっていて、集中する画面としては騒がしい。

6. **ダークモードが背景を黒くしただけ。** 育成のビジュアルとの相性を含めて再検討したい。

### 制約

- ボトムナビの見た目は変更しない
- パーセント表示は使わない（段階名で表す）
- 途中でやめた人を責める表現を入れない
- Android の縦画面・片手操作が前提

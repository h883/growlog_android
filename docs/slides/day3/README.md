# DAY3 アイディア出しテンプレート集（スライド）

プログラミング学習会 DAY3「プロダクト制作に向けて アイディアをふくらませよう」の
配布スライドを、元PDFのテンプレートに合わせて HTML で作り直したもの。

`index.html` をブラウザで開くだけで動く。ビルド不要、外部依存は Google Fonts の Noto Sans JP のみ。

## 構成（全17枚）

| # | スライド | 種別 |
|---|---|---|
| 1 | 表紙 | — |
| 2 | もくじ | — |
| 3 | はじめに：テンプレート集の使い方 | まとめ |
| 4 | 4つの切り口を、くらべてみる | まとめ（新規） |
| 5–6 | アプリのアイデアノート（使い方／シート） | 🟡 |
| 7–8 | App Store リリース予告シート（使い方／シート） | 🔵 |
| 9–10 | SNS PR動画企画コンテ（使い方／シート） | 🟢 |
| 11–12 | クラファン風アプリ開発プロジェクト（使い方／シート） | 🟠 |
| 13–16 | 印刷用（記入例なしの空シート×4） | — |
| 17 | シートが埋まったら、DAY3の開発へ | まとめ（新規） |

4 と 17 は元PDFにはない、内容をまとめ直したスライド。
4 は4枚のシートの違いと向き不向きを一覧にしたもの、17 は
どのシートを選んでも最後は WHO / WHAT / HOW の3点に行き着くことを示したもの。

## 操作

| キー・ボタン | 動作 |
|---|---|
| `→` / `Space` / `PageDown` | 次のスライド |
| `←` / `PageUp` | 前のスライド |
| `Home` / `End` | 最初 / 最後へ |
| `O` | 一覧（サムネイル）表示の切り替え |
| `Esc` | 一覧を閉じる |
| 「印刷 / PDF」ボタン | 1枚1ページで印刷・PDF出力 |

URL の `#6` のように番号を付けると、そのスライドを直接開ける。

## 印刷

「印刷 / PDF」ボタン（または `Ctrl/Cmd + P`）で、1スライド＝1ページの
1280×720 横向きページとして出力される。背景色も印刷されるよう
`print-color-adjust: exact` を指定してあるので、ブラウザの印刷設定で
「背景のグラフィック」を有効にすること。
13–16枚目が記入用の空シートなので、そこだけ印刷して配布できる。

## デザイン

元PDFから抽出した値をそのまま CSS 変数にしている。

| 用途 | 値 |
|---|---|
| 文字・枠線（インク） | `#253440` |
| アイデアノート | `#f1ca05` |
| App Store シート | `#71b6f1` |
| SNS PR コンテ | `#31d96c` |
| クラファン風 | `#ff7958` |
| もくじ背景 | `#f1f2f1` |
| 記入欄の下地 | `#f6f8f9` |

スライドは 1280×720 固定で組み、表示時に画面サイズへ `transform: scale()` で合わせている。
